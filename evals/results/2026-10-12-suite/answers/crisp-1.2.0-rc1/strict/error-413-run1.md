Use this message:

> **File is too large**
> The file is larger than the 25 MB limit. Compress the file or divide it into smaller parts. Then upload again.
>
> Error code: ERR_UPLOAD_413

I made two choices:

- The error code stays at the end so support staff can find the problem fast. Remove it if your users do not need it.
- The message says "file" and assumes the 25 MB limit applies to each file. If the limit applies to the total of many files in one upload, use this text: "The files are larger than the 25 MB limit in total. Upload fewer files at one time."
