Here is a rewrite for end users:

**This file is too large to upload**

The file is bigger than the 25 MB limit. Choose a smaller file, or reduce the size of this one, and try again.

If you need to share a large file, split it into smaller parts and upload each part.

If your app has a "Learn more" link, you can add it after the first paragraph. I assumed the limit is the same for all users and file types. If your plans have different limits, show the limit for the user's plan.

Keep the original error code, `ERR_UPLOAD_413`, in your logs or in a "Details" section. Support staff can use it, but most users do not need to see it.
