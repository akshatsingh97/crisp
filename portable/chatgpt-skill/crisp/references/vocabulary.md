# Crisp vocabulary

This list is ours. It is not the ASD-STE100 dictionary. The official dictionary (about 900 approved words) is copyrighted by ASD. You can get it free from asd-ste100.org.

The rule is the same as in STE: **one word, one meaning, one part of speech.**

## 1. Plain-word substitutions (lite and strict)

If a word carries no fact, delete it. Do not replace it.

| Phrasal verb | One-word verb |
|---|---|
| set up | install, configure, create |
| find out | learn, discover |
| figure out | find, calculate, solve |
| go down / go up | decrease / increase |
| put off | delay |
| look into | examine |
| carry out | do |
| come up with | make, create |
| get rid of | remove |
| make sure | make sure is permitted (it is the STE form for "ensure") |
| turn on / turn off | (permitted for physical switches and settings) |

## 3. Pick one word for each concept

In one answer, use one word for each concept. Common rotations to collapse:

- check / verify / confirm / validate / ensure → "make sure that", or one verb only
- config / configuration / settings / options → one noun
- run / execute / invoke / launch → one verb
- error / issue / problem / bug → "error" for errors, "failure" for failed operations
- delete / remove / drop / destroy → one word for each meaning
- show / display / render / present → one verb
- user / customer / client / end user → one noun

## 4. Strict mode: word discipline

In strict mode, also apply these rules.

S1. Use each word only as one part of speech. Use "test" and "check" as nouns: "Do a test of the pump." For the verb, write "make sure that".
S2. Use "help" only as a verb. For the noun, write "aid".
S3. Use "above" and "below" only for physical position. For limits, write "more than" and "less than".
S4. Use "follow" only to mean "come after". For obey, write "obey".
S5. Use the "-ing" form only as a noun or adjective ("the logging level"). Do not use it as a verb after a comma ("..., making it faster").
S6. Use the past participle only as an adjective ("the cached file"). Do not use it in passive or perfect tenses.
S7. Do not use technical nouns as verbs ("Slack me", "Google it", "PR the change").
S8. Prefer the shortest common word. If two words have the same meaning, use the word that a 12-year-old knows.
S9. Tell the user one time that full STE compliance needs the official ASD-STE100 dictionary.
